# AI-Powered CRM Contact Enrichment & Lead Scoring System

## Business Problem

Sales teams inside B2B businesses waste significant time on leads 
that were never going to convert. A contact is added to a CRM and 
a salesperson manually researches them before deciding whether to 
follow up. That research process takes time that compounds across 
hundreds of leads. The deeper problem is inconsistency: two 
salespeople doing manual research will assess the same lead 
differently. There is no standard scoring framework, no guaranteed 
enrichment, and no audit trail showing why a lead was prioritized 
or deprioritized.

## System Solution

When a new contact row is added to a Google Sheet acting as a 
lightweight CRM, the workflow triggers automatically. An AI agent 
equipped with an HTTP Request tool calls the Abstract API Company 
Enrichment endpoint to fetch publicly available company data based 
on the contact's company name. The agent combines the fetched data 
with the contact's own details to generate an enriched profile 
including company domain, industry classification, and a company 
summary. It then assigns a lead score of HIGH, MEDIUM, or LOW with 
a one-line reason. The enriched data is written back to the same 
Google Sheet row using an Update Row node, and the sales team 
receives a Slack notification with the full enriched profile 
and score.

## Tools Used

- n8n (automation engine)
- Google Sheets (lightweight CRM and trigger)
- Google Gemini (AI agent with agentic HTTP tool use)
- Abstract API (company enrichment data)
- Slack (sales team notifications)

## How to Use This Workflow

1. Download the workflow.json file
2. Open n8n and go to Workflows
3. Click Import and select the file
4. Connect your Google Sheets, Gemini, and Slack credentials
5. Update the Google Sheets document ID to your CRM sheet
6. Replace the Abstract API key in the system prompt 
   with your own key from abstractapi.com
7. Confirm your sheet headers match the column names 
   referenced in the Update Row node
8. Activate the workflow and add a test contact row 
   to your sheet to confirm

## Key Features

- Google Sheets trigger fires automatically when a new 
  contact row is added, no manual workflow execution needed
- AI agent equipped with an HTTP Request tool that it 
  calls dynamically during its reasoning process to fetch 
  real company data from an external enrichment API
- Enrichment outputs include company domain, industry 
  classification, and a one-paragraph company summary 
  generated by combining API data with contact details
- Lead scoring assigns HIGH, MEDIUM, or LOW based on 
  job title seniority, company establishment, and 
  service interest alignment
- Update Row node writes enriched data back to the 
  exact row that triggered the workflow using email 
  as the unique matching column
- Sales team receives a structured Slack notification 
  with the full enriched profile and score immediately 
  after enrichment completes

## Business Impact

- Sales team receives pre-researched and pre-scored 
  leads instead of raw contact data
- Manual research time eliminated for every new contact
- Consistent scoring framework applied to every lead 
  regardless of who added them
- CRM stays enriched automatically without any 
  manual data entry
- High-fit leads surface immediately so the team knows 
  exactly who to prioritize

## Known Limitations

- Company enrichment depends on the Abstract API 
  returning results: lesser-known or Nigerian SMB 
  companies may return limited or no data
- Google Sheets trigger polls every 5 minutes, 
  meaning new contacts wait up to 5 minutes 
  before enrichment runs
- Lead scoring is AI-generated and may not perfectly 
  reflect the sales team's internal qualification 
  criteria without customization
- Google Sheets is used as a lightweight CRM, not 
  a dedicated CRM platform with relationship tracking

## Planned Improvements

- Replace Google Sheets with a dedicated CRM such 
  as HubSpot or Pipedrive using their native APIs
- Add a confidence score to the enrichment output 
  indicating how reliable the fetched data is
- Build a re-enrichment trigger that updates stale 
  records automatically after 30 days
- Implement webhook-based triggering to eliminate 
  the polling delay
